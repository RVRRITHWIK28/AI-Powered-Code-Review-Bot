# AI-Powered Code Review Bot

AI-powered code review platform that analyzes source code, detects bugs, evaluates quality, and provides intelligent improvement suggestions using Google Gemini AI.

---

# 🤖 Overview

AI-Powered Code Review Bot is a Streamlit-based web application that performs intelligent code reviews using Google's Gemini AI. Users can upload source code files, receive detailed AI-generated feedback, view analytics, store review history, and download professional PDF reports.

---

# 🚀 Features

- 🤖 AI-Powered Code Review using Google Gemini AI
- ⭐ Code Quality Score
- 🐞 Bug Detection
- 🔒 Security Analysis

- 📋 Best Practice Recommendations
- 📄 Downloadable PDF Reports

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/RVRRITHWIK28/AI-Powered-Code-Review-Bot-Streamlit.git
```

Go to project folder

```bash
cd AI-Powered-Code-Review-Bot-Streamlit
```

Create virtual environment

```bash
python -m venv .venv
```

Activate

Windows

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

Run the application

```bash
streamlit run app.py
```
